One KPI card for every dashboard

Today the Stress Testing headline cards and the CRiSP VaR threshold cards are two separate designs. This replaces both with one <KpiCard> driven by a definition from the service. The definition says what the value is, how to format it, which direction is “worse”, what to compare against, and which threshold applies. The card works out the change, the status and the colours, and switches layout from its own width. All numbers on this page are invented.

02
Variants
Six layouts from the same definition. variant: "auto" picks one from the data: a threshold → detail; a pair of horizons → pair; otherwise headline. Dashboards can override it.

    

  


  
  

    
03
States
Every card handles loading, errors, missing data, stale data and selection the same way, so dashboards never need custom code for them. Colour comes from meaning (worse or better, breach or warning), never from the sign of the number.

    

  


  
  

    
04
Scaling
The card adapts to its container, not the screen. That matters in the custom dashboard, where a user can make a card a quarter-width or full-width. A group of cards can grow from 4 to 40 without a new design.

Before / after
How the two existing cards map onto the new one (invented values).

    

      

        
CRiSP VaR threshold card

          

            
Trading 10D
COB:266.80
PCOB:228.41
Diff:38.39
Diff %:16.81
Threshold:15
% Threshold:112

            

          

          
  • The whole card was salmon, so every card looked “in breach”. Now colour appears only when the threshold is crossed: a red rail, a Breach badge and a red meter.
  • The value is the hero; COB/PCOB/Diff move to a small detail list.
  • “% Threshold” becomes a meter with a marker at 100%, so “how close” is visible at a glance.
  • Trading 1D and 10D can share one card (the pair variant), which halves the 8-card row.

        

      

      

        
Stress Testing headline card

  • Same information, same reading order, so users won't need retraining.
  • Red now means worse (loss grew), driven by polarity. A smaller loss shows green, even though the number is negative.
  • An optional sparkline shows whether the jump is new or part of a trend.
  • The selected (cross-filter) state gets a ring and a “Filtering” badge, not just a border.

        

      

    

  


  
  

    
06
Contract
The service sends definitions (stable, saved with the dashboard) and values (per COB). The card derives Diff, Diff %, the threshold usage and the status, so every dashboard calculates them the same way. The service can override the status or colours when it knows better, e.g. a limit breach decided upstream.
